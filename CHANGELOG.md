## [1.0.0] - 2026-03-15

### Added
- COSTAR prompt builder with guided fields: Role, Context, Objective, Style, Tone, Audience, Response Format, and Initial Analysis
- One-click copy of the full formatted prompt to clipboard
- Local SQLite database to save and manage prompts
- Ability to save prompts as reusable templates
- Favorite/star system to highlight important prompts
- Search functionality by title, content, and tags
- Prompt history dialog with filter options (All, Templates, Favorites)
- Dark mode toggle
- Export prompts to JSON
- Import prompts from JSON
- Cross-platform support: Windows, macOS, and Linux
- NSIS installer script for Windows distribution
- Separate PyInstaller spec files per platform
